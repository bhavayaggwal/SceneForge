## 3. How to restart

```powershell
cd app
npm start                  # http://127.0.0.1:5180   (npm run build first if src/ changed)
npm test                   # 9 tests
node scripts/ask.ts dining-room-9407 "How many chairs are there?"
node scripts/mcp-smoke.ts  # MCP check; needs the app running and a scene open in a tab
```

A fresh machine runs `app\scripts\setup.ps1` first. Don't use `npm run dev` during a scan: saving a client file reloads the page and kills the scan.

## 4. Next steps, in order

1. **Commit.** Branch off `main`, commit `app/`, `spike/`, `docs/`, `Doc.md`, `README.md` and `.gitignore`. Ask the owner about `.agents/` and the old folders.
2. **Test the untested MCP tools:** `add_pin`, `fly_to`, and `index_scene` (a long call; check the MCP client's timeout).
3. **Evaluation (plan day 13).** Write `app/scripts/eval.ts` to score find and count against ground truth.
   - InteriorGS (HF `spatialverse/InteriorGS`, gated, ~44 MB per scene, 3D object labels) for counting and finding.
   - VSI-Bench (HF `nyu-visionx/VSI-Bench`, Apache-2.0) questions: video → pipeline → ask.
   - Own phone captures with tape-measured distances for measurement error.
   - Report precision and recall per label and the error in metres.
4. **Detection quality**, the main weakness (Doc §13):
   - Tile each view (2×2 crops at 768 px) so small objects get more pixels; it costs scan time.
   - Disambiguate merged neighbours: for two same-label boxes in one view, keep both even when their 3D points are close.
   - Optional: Grounding DINO or OWLv2 as a second detector (needs torch **cu126** for Pascal).
5. **Speed:** try Spark `lod: true` for the 1 M-splat room (about 12 fps now), and fewer, better views.
6. **Packaging (day 14):** a `start.ps1` that builds if needed, starts Ollama and the server, and opens the browser.
7. **Demo (day 15):** record find → count → measure → fit, plus an MCP session in Claude, and write the portfolio piece.
8. **Small UX gaps:** "Set as home view" (API exists), dismiss failed jobs, show the camera path for video scenes.
9. **Stretch:** "remove the chair": hide the splats inside an indexed object's 3D box (Spark edits).

## 5. Things that will bite

These are explained in Doc §12.

- Use `qwen3-vl:4b-instruct`, never the plain `qwen3-vl:4b` tag.
- Don't set `SF_NUM_GPU` unless the viewer is closed.
- Rebuild (`npm run build`) after editing `src/`; `npm start` serves `dist/`.
- The browser automation tool's tab titles lag; check the app state with JS.
- Each scan takes about 10 min of GPU, so run one at a time and don't start a Brush training at the same time.
